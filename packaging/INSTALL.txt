Hairball install, remove and use (works fully offline)
=====================================================

What you get: two plugins from the same code.
  Hairball     for instrument tracks (MIDI in, drop an audio file, play it with the keys).
  Hairball FX  for audio tracks (the track's sound goes through it; freeze, hold, riser). It also takes MIDI where the host allows.
Both have the same window and the same controls.

Windows
  Run windows\Hairball-Setup.exe. It installs: the two VST3 plugins for your DAW
  (C:\Program Files\Common Files\VST3, fixed location, all users), the standalone app and the manual
  (C:\Program Files\Studio 87\Hairball, the folder the installer asks about).
  Windows may show a blue "unknown publisher" screen because the installer is not signed:
  click "More info", then "Run anyway".
  Remove: Settings > Apps > Hairball > Uninstall. It asks if you also want your saved presets deleted
  (default is No, so they stay).

macOS
  Open macos\Hairball-macOS.pkg. It installs the two VST3 plugins, the standalone app, the manual and "Uninstall Hairball".
  The installer is not notarized: if macOS blocks it, open System Settings > Privacy & Security and choose "Open Anyway".
  Remove: open "Uninstall Hairball" in the Applications folder. It asks if you also want your saved presets deleted
  (default is Keep).

Linux, DAW installed as a Flatpak (for example Bitwig, Reaper or Ardour from Flathub)
  1. Your DAW should use the org.freedesktop.Platform 25.08 runtime (check with: flatpak info <DAW id>, Runtime line).
  2. Install the file from the linux folder:
       flatpak install --user linux/Hairball-flatpak-25.08.flatpak
  3. Restart the DAW and rescan plugins.
  Remove: flatpak uninstall --user org.freedesktop.LinuxAudio.Plugins.Hairball   (removes both plugins completely)

Linux, DAW installed natively
  Extract linux/Hairball-linux-vst3.tar.gz into ~/.vst3  (create the folder if needed), then rescan plugins.
  Remove: delete the Hairball.vst3 and Hairball FX.vst3 folders from ~/.vst3.

Your saved presets (kept on remove unless you choose to delete them)
  Windows : %APPDATA%\Studio 87\Hairball\presets
  macOS   : ~/Library/Application Support/Studio 87/Hairball/presets
  Linux   : ~/.config/Studio 87/Hairball/presets  (a Flatpak DAW keeps its own copy under ~/.var/app/<DAW id>/config/)
  To delete them yourself, remove the Studio 87/Hairball folder at that place.

Loading sounds: drop a WAV, AIFF, FLAC or OGG file on the display (or click Load audio). The session remembers the file's location,
so keep the file where it is. Captured audio is stored inside the session.

Manual: Hairball-manual.pdf (every control, the interface tour and recommendations).
Checksums: SHA256SUMS.
